ADR-002: Authentication and Identity ManagementStatusProposedDate2026-09-08Decision MakersEnterprise ArchitectIdentity & Access Management LeadSecurity ArchitectContext and Problem StatementThe authentication model determines how users access QuickSight, how identities are provisioned and managed, and which multi-tenancy patterns are available. Enterprise edition supports three identity models: IAM Identity Center, SAML 2.0 federation via IAM roles, and Microsoft Active Directory via AWS Directory Service.
